# Personal Portfolio Website - Erda Deniz ALP

This is a simple and responsive personal portfolio project developed using **HTML** and **CSS**, showcasing basic frontend development principles and layout techniques.

## 🔍 Features

- Responsive design (optimized for mobile and tablet screens)
- Navigation bar with internal section links
- Hero section with a profile image and introduction
- Trainings and courses sections with styled content
- Simple contact form and social media icons
- Font Awesome icons and Google Fonts integration

## 📁 Project Structure
project/ │ ├── index.html # Main HTML structure ├── css/ │ ├── global.css # Global styles (shared across the site) │ ├── main.css # Desktop styles │ ├── mobile.css # Styles for devices under 768px │ └── tablet.css # Styles for devices under 500px └── ogeler/ └── image/ # Contains all images used

## 📚 Technologies Used

- HTML5
- CSS3 (Media Queries)
- Font Awesome (icons)
- Google Fonts (Open Sans)
